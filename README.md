Pandas Crash Course for Data Science

A beginner-friendly Python program demonstrating the fundamentals of Pandas for Data Science.

Topics Covered

- Pandas Series
- DataFrames
- Creating and inspecting datasets
- Selecting rows and columns
- Data filtering
- Adding and modifying columns
- Sorting
- Handling missing values
- GroupBy operations
- Aggregation
- Apply functions
- Merging DataFrames
- Concatenating DataFrames
- Unique values and value counts
- Basic statistical analysis
- Date and time operations
- Reading and writing CSV files
- Mini sales-data analysis project

Requirements

Python 3.x

Install Pandas:

pip install pandas

Running the Program

python pandas_crash_course.py

Purpose

This project was created as a practical crash course for learning Pandas as part of Fundamentals of Data Science.
